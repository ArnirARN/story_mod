# Story Mod

Сюжетный мод для Minecraft **1.21.1** на **NeoForge**. Рассчитан на кооперативное прохождение на сервере с друзьями: прогресс сюжета общий для всех игроков.

> ⚠️ **Спойлеры.** Весь сюжет лежит в `src/main/resources/data/storymod/` (диалоги, записки, лут). Если хотите пройти мод сами, не открывайте эти файлы.

## Что внутри (без сюжета)

- NPC с собственными скинами, с которыми можно поговорить (ПКМ).
- Окно диалога: текст печатается постепенно, ответы выбираются кнопками или клавишами `1`–`9`. Пробел или клик пропускают анимацию.
- Ветвящиеся диалоги: варианты ответа появляются в зависимости от того, что вы нашли и узнали.
- Задания в свободном порядке, привязанные к ванильным структурам всего мира, включая Нижний мир и Край.
- Записки, которые можно найти в сундуках. Их читают как обычные книги.
- Несколько концовок.
- Личные роли игроков со своими заданиями, местом появления и предметами. Роли назначаются по нику при первом входе: `ArnirA` и `sserutto`.
- Личные стартовые наборы с особым предметом и способностью для каждой роли.
- Артефакты-талисманы, которые работают, пока лежат в инвентаре. Встречаются в сундуках ванильных структур.
- Curios API встроен в мод: артефакты можно надевать в слоты «Шея», «Кольцо» и «Талисман». Из инвентаря они тоже работают.
- Пять собственных структур со своими сундуками: в лесах и равнинах, в пустыне, в снегах и в горах. Найти командой `/locate structure storymod:<имя>`: `white_sanctuary`, `keeper_workshop`, `order_tower`, `sand_observatory`, `frost_crypt`.
- Странствующая торговка, которая приходит по расписанию, меняет диковины на изумруды и даёт побочные задания.
- Дневник у каждого игрока (ПКМ): показывает только его текущие цели и то, что он уже знает.
- Часть событий требует подождать несколько игровых дней, прийти в определённое время суток, фазу луны или место.

## Моды в сборке

Список лежит в `pack/mods.json`. CI сам находит на Modrinth свежую версию каждого мода для NeoForge 1.21.1 вместе с зависимостями, собирает `storymod.mrpack` и `server-mods.zip` и запускает сервер со всеми модами, чтобы проверить, что они грузятся вместе. Полный список с версиями есть в описании релиза.

Сюжет мягко подстраивается под установленные моды: связанные с модом задания и события появляются, только если этот мод стоит (условие `"mods": ["create"]` в данных). Twilight Forest и Deeper and Darker не входят в сборку (их нет на Modrinth для NeoForge 1.21.1), но если поставить их вручную, связанные с ними события тоже заработают.

## Сборка

Нужна Java 21.

```bash
./gradlew build
```

Готовый мод: `build/libs/storymod-<версия>.jar`.

Запуск для разработки: `./gradlew runClient` или `./gradlew runServer`.

Автотесты сюжета: `./gradlew runGameTestServer`. Они проходят все ветки диалогов, концовки, задания по времени и выпадение предметов на настоящем сервере с тестовыми игроками. В GitHub Actions тесты запускаются на каждый пуш.

## Установка

Свежая сборка всегда лежит в релизе [latest](https://github.com/ArnirARN/story_mod/releases/tag/latest). Curios API уже встроен в jar мода, отдельно ставить ничего не нужно.

**Игрокам (проще всего):** скачайте `storymod.mrpack` и импортируйте его в [Modrinth App](https://modrinth.com/app) или [Prism Launcher](https://prismlauncher.org/). Лаунчер сам поставит Minecraft 1.21.1, NeoForge и мод.

**Вручную:** поставьте NeoForge для 1.21.1 (21.1.x) и положите `storymod.jar` в папку `mods`.

**Сервер:** свежий NeoForge 21.1.x для 1.21.1 (версия указана в описании релиза), `storymod.jar` и содержимое `server-mods.zip` в папке `mods`. **Начните новый мир:** сюжетные предметы и новые структуры появляются только в ещё не сгенерированных чанках, а вступление запускается при первом входе игрока.

## Команды администратора

Нужен уровень оператора 2. Могут показать спойлеры.

| Команда | Что делает |
| --- | --- |
| `/story spawn <персонаж>` | Призвать персонажа рядом, если он потерялся |
| `/story flags` | Показать флаги сюжета (спойлер!) |
| `/story flag set\|clear <флаг>` | Поставить или снять флаг |
| `/story role <игрок> wanderer\|keeper\|none` | Назначить личную роль (если ник другой) |
| `/story reset` | Сбросить сюжет. Вступление начнётся заново при следующем входе |

## Как устроен контент

Сюжет полностью описан данными, код менять не нужно:

- `data/storymod/dialogues/<персонаж>.json` — диалоги. `entries` выбирают стартовый узел по условиям, `nodes` содержат текст, действия и варианты ответа.
- `data/storymod/triggers/*.json` — события, которые срабатывают сами, когда условие выполнено (один раз на мир или на игрока).
- `data/storymod/journal/*.json` — строки дневника и условия, когда их показывать.
- `data/storymod/loot_table/` и `data/storymod/loot_modifiers/` — что и с каким шансом добавляется в ванильные сундуки.
- `assets/storymod/textures/entity/npc/<персонаж>.png` — скин персонажа (обычная раскладка скина игрока 64×64).

Условия: `flags`, `not_flags`, `pflags`, `not_pflags`, `role`, `not_role`, `role_near`, `items`, `carry_pages`, `flag_count`, `days_since`, `time`, `moon_phase`, `dimension`, `near_anchor`, `advancement`, `any`, `not`.
Действия: `set_flag`, `clear_flag`, `set_pflag`, `clear_pflag`, `title`, `give_item`, `give_item_all`, `take_item`, `give_loot`, `spawn_npc`, `despawn_self`, `despawn_character`, `become_boss`, `broadcast`, `message`, `effect`, `sound`, `lightning`.
