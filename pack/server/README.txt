Сервер Story Mod

1. Нужна Java 21.
2. Запустите start.bat (Windows) или start.sh (Linux/macOS).
   При первом запуске скрипт сам поставит NeoForge и спросит про лицензию Minecraft.
3. При каждом запуске скрипт сам скачивает и обновляет серверные моды.
   Новые версии сборки подтянутся при следующем перезапуске сервера.

Память для сервера: файл user_jvm_args.txt (появится после первого запуска), например -Xmx6G.
